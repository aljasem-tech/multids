# Documentation Index

This repository contains documentation in the `docs/` folder. Key pages:

- `docs/quickstart.md` — installation and simple examples
- `docs/usage.md` — longer usage examples for connectors
- `docs/api.md` — API reference and public surface

To render these files locally you can use any Markdown viewer or a static site generator such as `mkdocs` or `pdoc`.

Quick render with `python -m http.server` from the project root will allow viewing the files in your browser.
